# Contributing to The Root Directory

Thanks for your interest in contributing! Here's how to get started.

## Ways to contribute

- Write a new file
- Report a bug or suggest a feature
- Improve the design or accessibility

## Reporting issues

Open an issue on GitHub and describe:
- What you expected to happen
- What actually happened
- Steps to reproduce

## Code of conduct

Be respectful. This is a community for learning, not for gatekeeping.
